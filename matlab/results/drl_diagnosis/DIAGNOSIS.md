# DRL 效果诊断与权威参考

本报告以当前工程源码、已训练 Agent、日志和 18 组实际 CarSim 闭环试验为依据。所有距离曲线和本报告误差指标统一为 **0–120 m**，使用该范围内的 MPC 采样点；完整原始仿真仍保存至约 150 m。未重新执行新配置的 300 回合训练。

## 结论与直接证据

当前 DRL 提升有限的重要可验证原因是动作范围过窄，较好的横向跟踪参数位于范围之外。原 Qy 上限为 13,800；保持 Np=40、Nc=12、Qpsi=2,800、Rdelta=13,500 及其余设置不变，固定参数探针将 Qy 改为 138,000，横向 RMSE 降低 **31.21%**。这证明本工况存在提升余量，但不证明新 DRL 已学会该设置。

扩范围探针的航向 RMSE 同时增加 **29.43%**。不能将它宣称为所有指标全面改善，更不能替换为“新训练策略”的成绩。它只是界定动作范围、建立候选权重集的实测依据。

| 设置 | 横向 RMSE / m | 最大横向误差 / m | 航向 RMSE / rad | QP 失败 |
|---|---:|---:|---:|---:|
| 固定 MPC | 0.09251726 | 0.25963884 | 0.01846167 | 0 |
| DDPG 300 回合 | 0.09179666 | 0.25883692 | 0.01693951 | 0 |
| TD3 300 回合 | 0.09612598 | 0.26553931 | 0.01477969 | 0 |
| 原范围内固定探针 | 0.08472201 | 0.24574788 | 0.01890723 | 0 |
| 扩范围固定探针（未训练） | 0.06364047 | 0.18961394 | 0.02389561 | 0 |

## 多方面检查结果

1. **动作范围与算法不匹配。** Qy 只能在 4,600–13,800 中选九档，Np 在 12–50 中取整数；连续 Actor 输出随后被四舍五入。实测零动作每个分量分别增加 0.01，映射参数全部不变。连续 critic 必须拟合带台阶的动作价值，可能使邻域梯度不可靠。这不意味着 DDPG 必须对环境求导，也不意味着它绝对不能学习。

2. **观测存在结构上的信息缺口。** 14 维 road_preview_v2 包含速度、道路预瞄、误差、上一转角和 Np，但未单独给出横摆角速度、侧偏角、上一转角增量和上一组 Q/R 权重。车辆动态、转角增量约束/代价及权重切换罚项依赖这些量，静态前馈策略不能充分区分相同观测下的不同动态状态。缺失量对本轮精度的影响幅度尚未通过重训消融定量确认。

3. **奖励主体已偏向横向精度，但峰值目标太宽松。** 精确拆解现有 C++ 奖励后，各项贡献如下：

| 控制器 | 横向误差占比 | 误差增长占比 | 峰值项占比 | 转向速率项占比 |
|---|---:|---:|---:|---:|
| fixed_np40_nc12 | 88.419% | 10.827% | 0.0122% | 0.0707% |
| ddpg_np40_nc12 | 89.232% | 10.024% | 0.0109% | 0.0774% |
| td3_np40_nc12 | 88.092% | 11.132% | 0.0373% | 0.0730% |

因此，“转向平滑奖励过大压制跟踪”不符合本轮数据。峰值阈值 0.25 m 与目前约 0.26 m 的峰值非常接近，使峰值项几乎不起作用；若目标是压到约 0.1 m，需要明确更严格的目标尺度，并单独验证。把负奖励简单改成正奖励没有证据能解决这些问题。

4. **探索、数据与收敛。** 每个算法实际交互 29,400 次，预热 550 次，噪声标准差 0.15 且不衰减；ResetFcn 只重置控制器，没有场景/初始状态随机化。单条名义轨迹反复训练可能缺少多样性，也不能据此证明泛化。DDPG 最佳记录评价回报在第 216 回合为 -36.0717，末回合为 -37.0682；TD3 最佳记录恰为末回合。增加回合并不保证单调变好。

5. **不能仅凭 MPC 权重数值大就削弱平滑。** 实测把 r_delta_change 从 960,000 降到 96,000，RMSE 从 0.09252 增至 0.11498 m；降到零增至 0.21947 m。这条看似合理的修改在本工况反而变差。固定 Np=12 时 RMSE 为 0.44073 m，说明当前动作集中还包含明显较差的时域；Np=50 也比 Np=40 差。

6. **已排除的主因。** 两个训练 Agent 均有非零参数更新；TD3 两个 critic 的参数最大差异为 2.30267，并非两个完全相同的网络；各对照试验 QP 失败均为零。考虑 Previous_Control_Result 的一个 MPC 周期延迟后，奖励逐决策重建误差如下，未发现奖励错位：

- DDPG 最大绝对误差：9.99e-16。
- TD3 最大绝对误差：1.02e-20。

## 选择的权威参考及其适用边界

TUM 的 Zarrouki、Spanakakis 与 Betz 论文 [A Safe Reinforcement Learning driven Weights-varying MPC](https://arxiv.org/abs/2402.02624) 采用先离线优化权重目录、再用离散 PPO 选择组合的路线；其高斯奖励横向尺度为 0.1 m，训练使用 1.5×10⁶ 步及随机赛道起点。可借鉴权重目录、匹配的离散策略和目标尺度；该研究的车辆、轨迹与采样周期不同，不能直接承诺复现其改善比例。

TD3 原作者 [公开实现](https://github.com/sfujim/TD3) 的 256×256 网络、3e-4 学习率、0.005 软更新、延迟 2、目标噪声 0.2 和截断 0.5，与当前关键数值基本一致。原实现还显式使用随机动作预热。故没有证据表明只把网络做大或再照抄这些超参数就能解决问题。

MathWorks [观测、奖励与终止信号官方说明](https://www.mathworks.com/help/reinforcement-learning/ug/define-reward-and-observation-signals.html) 强调观测应提供足够状态信息，奖励与下一观测对应且保持因果性，多项奖励需核对相对尺度。本次据此进行了状态检查、逐项奖励分解及延迟对齐核验。

## 建议的下一版实验顺序

1. 先固定 Np=40、Nc=12，使用实测权重候选，明确横向与航向共同约束。先消除空间限制，不直接把扩范围探针替换成默认控制器。
2. 二选一：保留 TD3/DDPG 时对三个 Q/R 动作采用连续对数插值；或参考上述论文，使用经过闭环验证的离散权重目录与 PPO/DQN。不要继续把连续动作学习与粗取整混在一起。
3. 补充横摆角速度、侧偏、误差变化率、上一组 Q/R 和转角增量等观测，并保持归一化。变更观测或映射后必须训练新 Agent，旧 Agent 不直接复用。
4. 奖励先保留横向二次损失；单独对比峰值阈值 0.25→0.10 m，再对比论文的 0.1 m 高斯目标。保持适度的航向与转向约束，避免仅改善横向却放大其他动态指标。不同奖励的原始回报数值不可直接横向比较。
5. 分别测试更新周期、噪声衰减和折扣因子，再用多个种子、速度/附着/初始偏差及独立评价工况验证。先做消融，再投入长训练，不能一次改动全部设置后归因。

上述是待验证的下一版实验方案，不是已完成的新 DRL 训练结果。当前默认参数、模型结构和原训练 Agent 均未被这些诊断探针替换。
