# 固定原车速的本轮校正

之前的曲率速度表把70 km/h目标降到了约56 km/h。该方案已退出默认入口、训练和对比流程；关联的旧验收文件已标明为历史降速实验。当前CarSim工况保持用户指定的70 km/h时间目标、原始路径和两路转向导入。

三自由度预测中的纵向速度仍按采样周期更新，影响轮胎力、转向刚度、坐标运动和`v²κ`侧向能力计算。它用于预测状态和诊断边界，不产生降速命令。速度Scope也明确标注曲率能力线为诊断量。

在原始70 km/h工况的155个0–120m样本中，未调参的原MPC横向RMSE为0.054056m，最大绝对误差0.148822m；先前校正/约束版本分别为0.054435m和0.061441m，已标为未改善。放宽非实测的5%能力预留，改善预测模型与转向前馈使用的轮胎刚度一致性，并降低转角变化惩罚后，选定固定参数组合在70 km/h工况取得：

- 横向RMSE：0.049971m，相对原基线改善7.56%。
- 最大绝对横向误差：0.146669m，相对基线改善1.45%。
- 最低/最高纵向车速：69.639/70.163 km/h，未启用调速。
- 最大侧向加速度：7.399m/s²；本工况约束最大超限为0，QP失败为0；松弛量最大0.000588。
- 最大质心侧偏角：3.013°；最大实际转角变化率43.27°/s，低于配置的120°/s实验限值。

本轮固定参数为转角变化权重240000、侧向约束利用率1.0、与轮胎有效刚度一致的前馈及ADMM最大迭代数20000。它们来自同一原始工况上的有限消融，结果不是跨工况泛化保证。预测校准仍是八状态近似模型的有效参数，而不是完整车辆系统辨识。侧向QP约束是软约束，须查看实际加速度、侧偏角、滑移角和松弛量。

新增约束QP与quadprog的3个抽样点核对中，2点收敛；X≈59.93m的一点有0.0363松弛量，达到20000次上限，残差约3.11e-4，独立解目标差约9.42e-5。它提示该状态下QP存在数值收敛余量，不能宣称全部独立抽样均已完全收敛。当前闭环运行记录中QP失败仍为0。

入口为 `run_corrected_preview`，仅在0–120m进行横向指标报告；所有对照使用相同70 km/h目标、路径和Np=40/Nc=12。代码修改和MATLAB/CarSim联合仿真在独立MATLAB进程完成；MCP仍无法附着，未声称由MCP执行。新环境DRL训练回合数为0，旧Agent仍属于原模型环境。
