## 论文到实现的对应

| 项目 | 论文 | 当前实现 |
|---|---|---|
| MPC | 转角增量、双线性离散、滚动优化 | 保留真实CarSim匹配的LTV增量MPC和七阶段求解 |
| 状态 | 横向/航向误差、两者变化率、车速、曲率；归一化[-1,1] | `paper_features.m`，六维SI状态、幅值归一化并限幅 |
| 动作 | q1、q3、λ，离散候选 | 三维连续Actor输出按论文候选取最近档，固定Np=40、Nc=12及Rdelta |
| 全局权重 | q2=q4=0，q5/R固定 | q_vy=q_r=0，取消旧轮胎侧偏附加代价，车身航向误差替代旧航迹方向误差 |
| 分步权重 | 式(22)：Qα,i=Qα exp(λ i/Np) | λ每周期进入真实MEX代价矩阵；λ变化触发QP参数更新并继承热启动 |
| 奖励 | 式(28)–(32)负绝对误差、转角平方、动作平方 | 权重300/50/60/15/15/20；已施加转角和上一策略动作通过显式延迟输入 |
| 更新周期 | TD3与MPC同步 | 均为0.04s，取消原策略0.08s/控制0.04s的异步结构 |
| 学习率/折扣 | Actor 1e-4，Critic 8e-4，γ=0.99 | 按表3设置 |
| 目标/回放/噪声 | τ=0.01，更新系数10，回放100000，批256，初始噪声0.4 | 按表3设置；更新系数解释为TargetUpdateFrequency=10 |

文中车速的记号与前文存在不一致，当前按纵向车速vx实现，并使用当前CarSim坐标系的运动学计算误差变化率。论文表1第二行标作q2，但2.4.1节和控制结构明确为航向权重q3。本实现按q3处理。候选为q1={25,55,85,115,155,200,240}，q3={100,300,500,700,900,1000,1100,1300}，λ={-1,-0.7,-0.5,-0.3,0,0.3,0.5,1}。

## 必须明确的工程差异与未公开项

1. **车辆与预测模型**：实际动力学仍来自当前CarSim车辆、轮胎与方向盘接口；保留现有较高阶预测模型，不套用论文2500kg货车参数，也没有重新生成目标轨迹。
2. **采样时间**：论文为0.01s，当前保持已验证的MPC 0.04s，策略同步到0.04s；Np/Nc保持用户要求40/12。γ虽取同值，物理折扣时间窗并不等同。
3. **绝对权重**：q1候选乘80、q3候选乘4以适配现有车辆；固定转角/增量/增量变化权重保留33000/13500/960000。论文为q5=50、R=10且没有增量变化附加项。因此本交付是论文方法适配版，不是仅替换车辆参数的严格数值复现。
4. **求解器**：论文OSQP，当前保留已有ADMM QP求解器；未将OSQP作为未经验证的新依赖引入。
5. **归一化和奖励尺度**：论文没有给出全部状态上下界与误差阈值。当前尺度为[0.25m,0.1rad,2m/s,0.5rad/s,30m/s,0.05/m]。动作平方项使用无量纲[-1,1]策略动作；直接平方原始q会使该项数量级失衡。此处属于明确的实现解释。
6. **未报告的训练细节**：网络沿用256×256，策略延迟2，预热256，噪声衰减5e-5、下限0.05；这些不是声称来自论文的参数。
7. **测试工况**：本次仍是当前名义CarSim工况；尚未复现论文的μ=0.6→0.4、额外2000kg载荷、变速和蛇形道路验证。不能搬用论文40.32%的标准差改善作为本项目成绩。

## Simulink结构优化

- 原模型派生独立版本，避免原300回合Agent被错误接到新维度。
- DRL与奖励模块的20路状态选择/合并封装为可展开State_Input_Adapter。
- 六状态归一化、全局权重与λ、论文奖励均有独立功能单元。
- 策略动作新增显式一周期延迟，奖励只评价已施加动作；控制模式通过Simulink对话参数传递，避免基础工作区与SimulationInput覆盖不同步。
- 新增原始动作日志和实际λ日志；所有中文注释使用宋体。
- 所有距离图限定0–120m；原始仿真保留完整数据，统计另存0–120m指标。

## 已完成验证

实际有效短训练：4回合、784次交互。Actor参数最大变化见`validation.json`，大于零；确定性评价到达150m，QP失败0。六维归一化状态与三维动作、候选映射、奖励逐时刻重建、λ改变QP解均已通过断言。

`lambda_qp_probe.csv`是在相同状态和全局权重下，将λ分别设为-1/0/1的求解结果，证明λ不是仅用于显示。`verification_120m.png`明确区分原固定控制器、论文结构适配固定控制器和仅4回合的短训策略。

**固定控制结构本身已改变，短训与原控制器的差异不能全部归因于TD3。正式效果还需新300回合训练及“匹配的固定权重/仅全局权重/全局+分步权重”三组对照、多种子和跨工况验证。**

初期接口排查产生的`paper_smoke`与`paper_checked_smoke`目录不是最终验证结果；本报告仅采用`paper_verified_smoke_ep4_seed42`及`paper_validation`。原实验数据不删除以便追溯。
