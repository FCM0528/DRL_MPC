# 当前 CarSim 工况的高速核验

2026-11-04 使用 `carsim_python_rl.ini` 的中性固定 MPC、当前 CarSim 车辆与参考轨迹的私有工况快照，分别将恒定目标车速改为 80、95、110 km/h。各仿真运行到 X=180 m；参考表范围为 0～130 m。统计采用完整仿真轨迹。结果目录为 `runs/highspeed_alignment_20261104/old_80`、`old_95`、`old_110`。三个快照的目标初速度分别为 80、95、110 km/h；除目标车速和运行输出路径外沿用相同设置。

| 目标速度 (km/h) | 横向 RMSE (m) | 最大横向误差 (m) | 最大侧偏角绝对值 (°) | 受限控制步数 | QP 未收敛步数 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 80 | 0.242 | 1.019 | 2.01 | 0 | 0 |
| 95 | 0.709 | 2.127 | 1.95 | 60 | 0 |
| 110 | 0.802 | 2.422 | 1.90 | 73 | 0 |

侧偏角以 CarSim 车体侧向和纵向速度计算 `atan2(vy, vx)`；大误差说明当前轨迹下跟踪不满足要求。侧偏角较小、QP 无失败或完成行程都不能证明闭环稳定、安全或避免越界。

本次保留原有高速转角速率调度与状态风险保护。针对该轨迹的诊断试跑在 110 km/h 将高速末端转角速率由 5°/s 提高到 25°/s 时，最大误差增至 4.60 m、最大侧偏角约 10.36°；提高到 37°/s 时分别为 13.08 m 和 17.49°。因此不能仅通过提高转角速率上限解决高速问题，也不能据此断定现有 5°/s 调度对所有工况安全。

当前控制接口只输出前轮转角，无法控制 CarSim 纵向速度。需要改进高速表现时，应在独立工况中联合评估路径曲率、可用附着、目标车速及控制约束；不要将当前模型或已有 60 km/h 强化学习策略直接用于高速工况。
