## 接口问题与修改

1. **暂存阶段覆盖了源导出接口。** 原代码删除所有 `EXPORT` 和 `PORTS_EXP`，再写入两个轮角导出，导致 CarSim 新增的 20 路导出实际没有进入 SDK 仿真。现保留源 Parsfile 和 Simfile 的导出定义，仅重定向私有仿真文件与结果路径。
2. **求解器包装层绑定了固定数组形状。** 原代码要求 `n_export == 2`，并将数组的前两项当成左右轮角。现按求解器实际通道数分配缓冲区；实际轮角与车辆状态统一通过 `vs_get_var_ptr` 按关键词读取 SI 值。导出数量和顺序不再决定状态含义。
3. **手动转角上限会绕过输入核对。** 现始终读取本轮 echo，核对所选转向输入的名称、索引、REPLACE 模式和单位。额外输入保留 echo 声明的初值，避免每个周期无条件清零。
4. **首周期默认假定前轮为零。** 固定与桥接入口现由实测左右前轮角均值初始化上一转角，避免非零初始转向时使用错误的增量基准。本轮实际初始轮角为零，因此不改变表中的工况指标。

| 通道位置（从 1 开始） | 当前导出 | 导出显示单位 |
| --- | --- | --- |
| 1–2 | Xcg_TM、Ycg_TM | m |
| 3–4 | Vx、Vy | km/h |
| 5–6 | Yaw、AVz | deg、deg/s |
| 7–8 | Ax、Ay | g |
| 9–10 | Steer_L1、Steer_R1 | deg |
| 11–12 | Beta、Rho_Road | deg、1/m |
| 13–16 | AlphL_L1、AlphL_R1、AlphL_L2、AlphL_R2 | deg |
| 17–20 | Fy_L1、Fy_R1、Fy_L2、Fy_R2 | N |

上述显示单位与变量指针的 SI 单位不同。新增量通过关键词绑定 SI 指针，记录在固定 MPC 与桥接 CSV 中；旧工况没有这些可选量时保留 NaN，报告空白表示不可用。

实际利用方式如下：

- `AlphL_*` 和 `Fy_*` 原已用于 MPC 的轮胎工作点与预测，本次继续使用，并补充前后轴力及力矩平衡诊断。
- `Beta` 可用时用于策略观测中的航迹角和奖励中的侧偏角；缺失时回退到 `atan2(vy,vx)`，观测维数仍为 14。当前实测二者数值一致，因此保持已有模型的观测含义。
- `Ax/Ay` 用于检验旋转车体系运动学：`dvx/dt = Ax + r*vy`、`dvy/dt = Ay - r*vx`。按实际时间戳和梯形区间平均计算，包含终点的部分步长，不把 g 显示值直接作为速度导数。
- 实际前轮角与对应控制指令对齐，诊断转向执行差；不把执行机构动态直接归因于 QP 求解失败。
- 当前 `Rho_Road` 恒为零，而 LTARG 目标曲率范围约为 −0.0271134 至 0.0244698 1/m。前者是驾驶员路径曲率，不能替代双移线目标轨迹预瞄；报告展示两者差值用于解释信号含义。

最终 TD3 回放的实测 Ay 峰值为 7.14078 m/s²、Beta 峰值为 2.19080°、轮角执行差 RMSE 为 0.107617°。纵向与侧向运动学残差 RMSE 分别为 0.018987、0.117663 m/s²，侧向力平衡残差为 0.034855 m/s²，横摆力矩平衡残差为 0.130704 rad/s²。这些量用于观察单位、坐标和模型近似，不作为任意阈值的通过判据；轴力诊断采用左右轮平均转角，未包括完整轮胎纵向力、侧倾和悬架动力学。

## 基础 MPC 检查

检查了坐标旋转、侧偏角和轮胎力方向、单轮到车轴力的倍数、CarSim 回显的质量和惯量、工作点仿射项、Tustin 离散化、增量前缀和、Nc 后保持末转角、角度和速率约束、ADMM 残差、调参时的热启动与失败回退。现有数值测试核对非线性方程的差分导数及 Tustin 矩阵恒等式，也检查不同车速下的合成直线闭环恢复。

本轮修复了两项内核防护缺口：直接构造 `LateralMpc` 时现在检查权重、采样周期、终端系数、求解器容差及车辆物理参数的有效性；预测失败后清除失效热启动，并将诊断控制序列重置为实际保持的转角。非有限状态和上一转角增量会进入明确的预测失败路径。

已检查部分没有发现增量约束矩阵、基本符号或离散化恒等式错误。当前模型仍采用静态轴荷、相同四轮轮胎表、近似松弛长度与饱和区斜率下限；每周期求解一次局部线性 QP，没有纵向减速输出、轮胎摩擦圆硬约束或完整闭环稳定性证明。QP 收敛和当前工况改善不能替代这些物理限制的验证。

## Python 与四组流程

四组比较现在会冻结固定 MPC 与 DRL 配置的完整继承链，和冻结的 CarSim 工况一起用于回放。无分段切点时也检查终点有限且位于起点之后；没有成功状态样本的回合会报告应检查求解器日志，替代原来的空数组下标异常。回放还读取模型训练 manifest，解析继承配置并核对控制、观测、动作与奖励设置；即使动作维数相同，候选值含义改变也会拒绝复用。缺少训练配置的模型标记为未核对。
