# DDPG、TD3、TQC 训练参数

以下是当前项目的实际默认值，修改入口是 `configs/rl_training.ini`。表中的采样周期、决策周期、折扣因子与四维动作范围由 `configs/carsim_python_rl.ini`（继承 `default.ini`）提供；Python 训练配置不会覆盖 MPC 的物理采样时间。所有学习率均实际应用于相应优化器。

## 三种算法共有的环境与训练设置

| 参数 | 当前值 | 来源与含义 |
| --- | ---: | --- |
| MPC 采样时间 | 0.04 s | `default.ini [mpc] dt_s` |
| 回合结束位置 | X = 120 m | 继承 `default.ini [simulation] distance_m`，与固定 MPC 相同 |
| 每次策略决策的 MPC 步数 | 2 | `carsim_python_rl.ini [rl] decision_steps` |
| 策略决策间隔 | 0.08 s | 0.04 × 2 |
| 未来奖励折扣因子 | 0.995967610541 | `carsim_python_rl.ini [rl] discount_gamma`，按策略决策生效 |
| 观测 / 动作维数 | 14 / 4 | 默认 `road_preview_v2`；动作依次为 Np、Qy、Qψ、RΔ |
| 训练回合数 | 300 | `rl_training.ini [training] episodes`，每种算法各自计数 |
| 随机种子 | 42 | `rl_training.ini [training] seed` |
| 经验回放池容量 | 100000 个决策 | `buffer_size` |
| 开始更新前采样数 | 550 个决策 | `learning_starts`；对应回合数随工况长度和车速变化 |
| 随机小批量 | 256 | `batch_size` |
| 更新间隔 | 每 1 个决策 | `train_freq` |
| 每次更新的梯度步数 | 1 | `gradient_steps` |
| 无探索验证及检查点间隔 | 550 个决策 | `eval_frequency`；用验证最佳检查点选模型 |

### 离散候选动作

| 自适应参数 | 候选值 |
| --- | --- |
| Np | 10, 11, 12, …, 49, 50 |
| Qy | 4600, 6000, 7500, 8250, 9200, 9850, 10500, 12000, 13800 |
| Qψ | 1400, 1800, 2300, 2550, 2800, 3150, 3500, 4400, 5600 |
| RΔ | 6750, 8500, 11000, 12250, 13500, 15250, 17000, 21500, 27000 |

先按当前工况 50–90 m 段的固定 MPC 横向 RMSE 扫参，选出 Nc = 7。零动作与 `default.ini` 对齐，使用 Nc = 7 下全程 RMSE 最低且可作为双向动作中心的 Np = 47，以及 Qy = 9200、Qψ = 2800、RΔ = 13500。关键段对比基准使用 Np = 50、Nc = 7。`q_tire_slip = 4000` 由固定配置提供。C++ 每次决策将三个权重动作映射到各自的九个候选值。`max_np_change_per_decision = 0` 时，量化后的目标 Np 在当次决策直接生效。

### 预瞄观测

| 顺序 | 输入 | 归一化前的量 |
| --- | --- | --- |
| 1 | 地速 | \(\sqrt{v_x^2+v_y^2}\) |
| 2–4 | 曲率 | 当前平滑曲率、预瞄内与当前曲率差值最大的有符号差、预瞄内最大 \(|d\kappa/dX|\) |
| 5 | 参考航向变化 | 前方 0.6 s 的参考切线角相对当前参考切线角的变化 |
| 6–8 | 附着与提前量 | 当前附着系数、预瞄内最大 \(v^2|\kappa|/(\mu g)\)、该比值首次达到 1 的剩余时间 |
| 9–12 | 闭环反馈 | 横向误差、质心运动方向误差、上一前轮指令、已执行 Np |
| 13–14 | 附着预警与近段需求 | 预瞄内最低附着系数、前方 0.6 s 内最大横向附着需求比 |

默认预瞄距离为沿道路纵向速度乘 2.0 s，限制在 10–50 m。40、60、80 km/h 匀速直行时分别对应约 22.2、33.3、44.4 m。静止时只用当前位置，接近终点时按剩余参考路段截断。历史配置省略距离上下限时采用原有的速度与预瞄时间乘积。启用 Np 变化限制的配置仍按决策周期和所需调整时间计算名义预瞄时间。附着需求沿路查询 CarSim 附着表。剩余时间按限幅后预瞄距离对应的时间归一化，窗口内未达到阈值时取 1。奖励继续按每个决策区间内的闭环误差、转向、稳定性与求解失败计算。

当前默认使用 14 维 `road_preview_v2`。归档的 12 维模型仍使用训练时冻结的 `road_preview` 配置。原 17 维模型需要使用训练时的旧版代码，迁移到当前版本须重新训练。

### 横向跟踪奖励与验收

主损失为 `2 × (|ey|/0.20)²`。单步绝对误差超出 0.25 m 时，再加 `3 × (max(0, |ey|−0.25)/0.25)²`。用质心速度与参考曲线斜率计算 `ey_dot`，以 `|ey + 0.25 s × ey_dot|` 估计短时偏差。如果估计的绝对误差大于当前值，对其增长量加归一化平方惩罚，权重为 0.6。该项对左右偏差对称，覆盖继续远离参考线和高速穿线后反向偏离。航向、转角、转向速率与稳定性仍作辅助项。训练回报按控制步损失聚合。

训练传入 `--fixed-config configs/carsim_fixed_key_segment.ini --lateral-key-segment 50 90 --require-lateral-improvement` 可启用本工况的验收口径。验证先要求完赛、QP 零失败、全程 RMSE 与最大绝对横向误差都低于固定 MPC，且 90 m 后最大绝对误差不高于固定 MPC，然后按 50–90 m RMSE 排名。实测值与是否合格记录在 `solver_validation/lateral_validation.csv`。没有合格模型时，训练仍输出最终模型及对比指标供诊断。

## 奖励与曲线

DDPG、TD3 和 TQC 共用 `tracking_v2`。横向误差按 0.20 m 归一化后取平方，超过 0.25 m 的部分另加平方惩罚。开启 `track_course` 时，角度项使用质心速度方向与轨迹切线的夹角。转角变化率按 100°/s 归一化，绝对质心侧偏角超过 5° 的部分增加平方惩罚。100°/s 和 5° 用于计算软惩罚。

每个策略决策取有效控制步的加权损失均值，再扣除事件罚值。每次 QP 未收敛扣 25，仿真失败或超时未完成扣 100。末决策块可能少于 4 个控制步，事件罚值保持相同。`reward_scale` 用于 C++ 逐步记录，桥接返回奖励前会除掉该尺度。

训练在质心首次到达或越过 X = 120 m 时结束。`manifest.json` 记录奖励版本和本次冻结的固定 MPC 配置。跟踪误差按控制后的状态样本统计。

## 负回报版本首轮验证（2026-11-02）

以下结果使用调整前的峰值奖励（阈值 0.30 m、权重 0.3）及训练参数，不能与本次新奖励的回报数值直接比较。

以当时的 TQC 参数和 60 km/h 工况从零训练 100 回合，训练回报前 20 回合均值为 **-42.13**，后 20 回合为 **-29.86**。每 500 个决策的无探索验证中，最佳检查点回报为 **-20.03**；同工况中性 MPC 为 **-23.49**。最佳检查点的横向 RMSE 为 0.05573 m（中性 0.06184 m），航向 RMSE 为 0.92284°（中性 1.00519°），两者都没有 QP 失败和附着保护步数。

验证回报有波动，最终模型回报为 -25.40，低于最佳检查点和中性 MPC。当前证据支持保存并继续验证最佳检查点，不能声称 100 回合内已经稳定收敛；应增加训练回合、不同随机种子及独立 CarSim 工况验证后再判断。

## 调整后同工况试跑（2026-11-03）

历史试验使用当时的奖励和训练参数，分别以种子 42、44 从零训练 TQC 100 回合。每回合约 55 个决策，验证间隔 550 个决策。两次训练的源 Simfile/Parsfile 指纹相同。以下为确定性策略在同一 60 km/h 工况上的结果。

| 控制器 | 验证回报 | 横向 RMSE (m) | 峰值横向误差 (m) | 航向 RMSE (°) | QP 失败 / 附着保护步数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 中性 MPC | -23.53 | 0.06184 | 0.35594 | 1.00519 | 0 / 0 |
| TQC 种子 42 最佳检查点（70 回合） | -20.85 | 0.05335 | 0.26787 | 0.98651 | 0 / 0 |
| TQC 种子 44 最佳检查点（40 回合） | -19.64 | 0.05205 | 0.28198 | 0.93504 | 0 / 0 |
| TQC 种子 42 最终模型 | -25.38 | 0.06259 | 0.34185 | 1.03137 | 0 / 0 |
| TQC 种子 44 最终模型 | -24.70 | 0.06292 | 0.31330 | 0.96686 | 0 / 0 |

两个最佳检查点均改善了本工况的横向 RMSE 和峰值误差，但最终模型均退化，训练未稳定收敛。0.25 m 是奖励开始额外惩罚的阈值，并非硬约束；本次最佳模型的峰值仍高于该值。部署前应从 `best/best_model.zip` 选模型，并在独立工况复测。详细指标与轨迹见 `runs/reward_tuning_validation/` 下两个训练目录的 `best_evaluation/` 和 `evaluation/`。
