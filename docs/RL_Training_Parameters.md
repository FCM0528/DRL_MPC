# DDPG、TD3、TQC 训练参数

以下是当前项目的实际默认值，修改入口是 `configs/rl_training.ini`。表中的采样周期、决策周期、折扣因子与四维动作范围由 `configs/carsim_python_rl.ini`（继承 `default.ini`）提供；Python 训练配置不会覆盖 MPC 的物理采样时间。所有学习率均实际应用于相应优化器。

## 三种算法共有的环境与训练设置

| 参数 | 当前值 | 来源与含义 |
| --- | ---: | --- |
| MPC 采样时间 | 0.05 s | `default.ini [mpc] dt_s` |
| 回合结束位置 | 当前参考轨迹终点 | `distance_m = reference_end`，取本次 CarSim `LTARG_TABLE` 的最后一个 X |
| 每次策略决策的 MPC 步数 | 4 | `carsim_python_rl.ini [rl] decision_steps` |
| 策略决策间隔 | 0.20 s | 0.05 × 4 |
| 未来奖励折扣因子 | 0.995967610541 | `carsim_python_rl.ini [rl] discount_gamma`，按策略决策生效 |
| 观测 / 动作维数 | 17 / 4 | C++ 桥接观测；动作依次为 Np、Qy、Qψ、RΔ |
| 训练回合数 | 500 | `rl_training.ini [training] episodes` |
| 随机种子 | 42 | `rl_training.ini [training] seed` |
| 经验回放池容量 | 100000 个决策 | `buffer_size` |
| 开始更新前采样数 | 550 个决策 | `learning_starts`；对应回合数随工况长度和车速变化 |
| 随机小批量 | 256 | `batch_size` |
| 更新间隔 | 每 1 个决策 | `train_freq` |
| 每次更新的梯度步数 | 1 | `gradient_steps` |
| 无探索验证及检查点间隔 | 550 个决策 | `eval_frequency`；用验证最佳检查点选模型 |

### 离散候选动作

| 自适应参数 | 候选值 |
| --- | --- |
| Np | 10, 12, 14, …, 48, 50 |
| Qy | 4600, 6000, 7500, 9200, 10500, 12000, 13800 |
| Qψ | 1400, 1800, 2300, 2800, 3500, 4400, 5600 |
| RΔ | 6750, 8500, 11000, 13500, 17000, 21500, 27000 |

候选值以 80 km/h、μ = 0.85 双移线工况的固定 MPC 标定为中心。零动作对应 Np = 28、Qy = 9200、Qψ = 2800、RΔ = 13500，Nc 固定为 8。C++ 每次决策将三个权重动作映射到数组索引，实际执行数组元素。Np 每次决策最多改变 2 步。

## DDPG

| 参数 | 当前值 | 作用 |
| --- | ---: | --- |
| Actor 学习率 | 0.0003 | 更新确定性策略网络 |
| Critic 学习率 | 0.0003 | 更新 Q 网络；可与 Actor 分别调整 |
| 目标网络软更新系数 τ | 0.005 | 每次梯度更新后软更新 |
| Actor 隐藏层 | 2 × 256 | `actor_hidden_layers` / `actor_hidden_width` |
| Critic 隐藏层 | 2 × 256 | `critic_hidden_layers` / `critic_hidden_width` |
| Critic 数量 | 1 | SB3 的 DDPG 实现固定为一个评论家 |
| 探索噪声标准差 | 0.15 | 归一化动作空间的独立高斯噪声，训练全程恒定 |
| 目标策略平滑噪声 | 0 | DDPG 无 TD3 目标平滑 |
| 策略与目标网络更新间隔 | 1 个梯度步 | DDPG 每步更新 |

## TQC

| 参数 | 当前值 | 作用 |
| --- | ---: | --- |
| Actor 学习率 | 0.0001 | 随机策略网络；减缓单工况后期策略漂移 |
| Critic 学习率 | 0.0003 | 分位数评论家网络 |
| 熵系数学习率 | 0.0001 | 自动熵优化器；减缓探索强度变化 |
| 目标网络软更新系数 τ | 0.005 | 分位数目标评论家 |
| 评论家数量 | 3 | `n_critics`；`paper` 命令行预设改为 5 |
| 每个评论家的分位数 | 25 | `n_quantiles` |
| 每个评论家截去的最高分位数 | 2 | `drop`；目标分布总共截去 3×2 个 |

| 目标网络更新间隔 | 每 1 个梯度步 | `target_update_interval` |
| 熵系数 / 目标熵 | auto / auto | 目标熵由四维动作空间自动确定 |
| 额外动作噪声 | 无 | 随机策略自身探索 |

## 奖励与曲线

DDPG、TD3 和 TQC 共用 `tracking_v2`。横向误差按 0.20 m 归一化后取平方，超过 0.25 m 的部分另加平方惩罚。开启 `track_course` 时，角度项使用质心速度方向与轨迹切线的夹角。转角变化率按 100°/s 归一化，绝对质心侧偏角超过 5° 的部分增加平方惩罚。100°/s 和 5° 用于计算软惩罚。

每个策略决策取有效控制步的加权损失均值，再扣除事件罚值。每次 QP 未收敛扣 25，仿真失败或超时未完成扣 100。末决策块可能少于 4 个控制步，事件罚值保持相同。`reward_scale` 用于 C++ 逐步记录，桥接返回奖励前会除掉该尺度。

训练在质心第一次达到本次参考轨迹终点时结束。`manifest.json` 会记录奖励版本。采用新奖励时需重新训练，再用同一工况和距离比较三种算法的横向 RMSE、最大误差、前轮转角速率、侧偏角与 QP 失败次数。

## 负回报版本首轮验证（2026-11-02）

以下结果使用调整前的峰值奖励（阈值 0.30 m、权重 0.3）及训练参数，不能与本次新奖励的回报数值直接比较。

以当时的 TQC 参数和 60 km/h 工况从零训练 100 回合，训练回报前 20 回合均值为 **-42.13**，后 20 回合为 **-29.86**。每 500 个决策的无探索验证中，最佳检查点回报为 **-20.03**；同工况中性 MPC 为 **-23.49**。最佳检查点的横向 RMSE 为 0.05573 m（中性 0.06184 m），航向 RMSE 为 0.92284°（中性 1.00519°），两者都没有 QP 失败和附着保护步数。

验证回报有波动，最终模型回报为 -25.40，低于最佳检查点和中性 MPC。当前证据支持保存并继续验证最佳检查点，不能声称 100 回合内已经稳定收敛；应增加训练回合、不同随机种子及独立 CarSim 工况验证后再判断。

## 调整后同工况试跑（2026-11-03）

历史试验使用当时的奖励和训练参数，分别以种子 42、44 从零训练 TQC 100 回合。每回合约 55 个决策，验证间隔 550 个决策。两次训练的源 Simfile/Parsfile 指纹相同。以下为确定性策略在同一 60 km/h 工况上的结果。

| 控制器 | 验证回报 | 横向 RMSE (m) | 峰值横向误差 (m) | 航向 RMSE (°) | QP 失败 / 附着保护步数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 中性 MPC | -23.53 | 0.06184 | 0.35594 | 1.00519 | 0 / 0 |
| TQC 种子 42 最佳检查点（70 回合） | -20.85 | 0.05335 | 0.26787 | 0.98651 | 0 / 0 |
| TQC 种子 44 最佳检查点（40 回合） | -19.64 | 0.05205 | 0.28198 | 0.93504 | 0 / 0 |
| TQC 种子 42 最终模型 | -25.38 | 0.06259 | 0.34185 | 1.03137 | 0 / 0 |
| TQC 种子 44 最终模型 | -24.70 | 0.06292 | 0.31330 | 0.96686 | 0 / 0 |

两个最佳检查点均改善了本工况的横向 RMSE 和峰值误差，但最终模型均退化，训练未稳定收敛。0.25 m 是奖励开始额外惩罚的阈值，并非硬约束；本次最佳模型的峰值仍高于该值。部署前应从 `best/best_model.zip` 选模型，并在独立工况复测。详细指标与轨迹见 `runs/reward_tuning_validation/` 下两个训练目录的 `best_evaluation/` 和 `evaluation/`。
