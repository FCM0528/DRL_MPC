# DDPG、TD3、TQC 训练参数

当前实验入口见[TQC主线与最新审计](DRL_MPC_Next_Stage_Analysis.md)、[主线恢复](DRL_MPC_Mainline_Recovery.md)与[文档索引](INDEX.md)。固定Np的1D/2D结果为动作消融。本文保留legacy接口及历史实验口径；当前模型选择使用双MPC基线及周期检查点，不以final模型替代验证选择。

优化器默认入口是 `configs/rl_training.ini`。当前统一预实验使用 `rl_training_pilot.ini`，每算法7900决策、seed42、每790决策验证；环境使用 `strong_weights3.ini` 的20维road_preview_joint、三维Qy/Qpsi/Rdelta、continuous_weights及joint_tracking奖励。零动作对应强MPC36/18400/8960/10800，控制/决策周期0.04/0.08s，权重限速1.08。full4增加每决策限速2步的Np，qy1/weights2为1D/2D消融；历史Np前缀3D不改义。Python训练配置不会覆盖MPC的物理周期，学习率分别实际应用于各优化器。

下表中的14维/四维/500回合是保留的CLI默认 `carsim_python_rl.ini`（继承default.ini）接口，不是当前主线推荐实验，也不是本轮执行计划。

## 三种算法共有的在线采样及legacy默认设置

训练样本来自在线 CarSim 闭环交互：当前观测 → 策略选择 Np/Qy/Qψ/RΔ → C++ MPC 求解转角 → CarSim 推进 → 返回下一观测、奖励和结束标记。每个经验元组都由实际环境调用产生，经验池可以重用本次训练先前回合的交互样本；不灌入扫参 CSV、固定 MPC 转角标签、历史报告或 MPC 预测轨迹。预瞄量来自 CarSim 参考轨迹和附着表，奖励由交互后的状态、控制动作及求解状态计算；短时误差增长项是基于当前实测状态的估计，不是读取未来车辆状态。

每种算法独立启动空经验池。前 550 个决策通过探索动作与环境交互采样，之后从已采集样本抽取小批量更新；当前每个新决策配一次梯度更新。`--resume` 只恢复模型及优化器，不加载历史经验池，也重新执行 550 个决策的采样预热。固定 MPC、零动作一致性与无探索验证使用独立环境，其数据不进入训练经验池。`manifest.json` 的 `training_data` 记录来源、初始/最终经验池大小、新采集决策数及梯度更新数，三算法套件的 `suite_manifest.json` 汇总三种策略的数据来源。

### 预瞄观测

| 顺序 | 输入 | 归一化前的量 |
| --- | --- | --- |
| 1 | 地速 | \(\sqrt{v_x^2+v_y^2}\) |
| 2–4 | 曲率 | 当前平滑曲率、预瞄内与当前曲率差值最大的有符号差、预瞄内最大 \(|d\kappa/dX|\) |
| 5 | 参考航向变化 | 前方 0.6 s 的参考切线角相对当前参考切线角的变化 |
| 6–8 | 附着与提前量 | 当前附着系数、预瞄内最大 \(v^2|\kappa|/(\mu g)\)、该比值首次达到 1 的剩余时间 |
| 9–12 | 闭环反馈 | 横向误差、质心运动方向误差、上一前轮指令、已执行 Np |
| 13–14 | 附着预警与近段需求 | 预瞄内最低附着系数、前方 0.6 s 内最大横向附着需求比 |
| 15–17（joint新增） | 车身航向、侧偏、横摆角速度误差 | 分别按heading_scale_rad、侧偏阈值及0.25rad/s归一化 |
| 18–20（joint新增） | 当前已执行Qy/Qpsi/Rdelta | 相对中性点的对数权重坐标 |

默认预瞄距离为沿道路纵向速度乘 2.0 s，限制在 10–50 m。40、60、80 km/h 匀速直行时分别对应约 22.2、33.3、44.4 m。静止时只用当前位置，接近终点时按剩余参考路段截断。历史配置省略距离上下限时采用原有的速度与预瞄时间乘积。启用 Np 变化限制的配置仍按决策周期和所需调整时间计算名义预瞄时间。附着需求沿路查询 CarSim 附着表。剩余时间按限幅后预瞄距离对应的时间归一化，窗口内未达到阈值时取 1。奖励继续按每个决策区间内的闭环误差、转向、稳定性与求解失败计算。

当前主线使用20维road_preview_joint；legacy的14维road_preview_v2和12维road_preview继续与其旧模型配套。不能加载旧14维策略作为20维模型续训。原17维模型需训练时旧版代码，迁移须重新训练。

### 历史横向跟踪奖励与验收（非当前joint选模）

主损失为 `2 × (|ey|/0.20)²`。单步绝对误差超出 0.25 m 时，再加 `3 × (max(0, |ey|−0.25)/0.25)²`。用质心速度与参考曲线斜率计算 `ey_dot`，以 `|ey + 0.25 s × ey_dot|` 估计短时偏差。如果估计的绝对误差大于当前值，对其增长量加归一化平方惩罚，权重为 0.6。该项对左右偏差对称，覆盖继续远离参考线和高速穿线后反向偏离。航向、转角、转向速率与稳定性仍作辅助项。训练回报按控制步损失聚合。

训练传入 `--fixed-config <固定MPC配置> --lateral-key-segment 50 90 --require-lateral-improvement` 可启用本工况的验收口径。验证先要求完赛、QP 零失败、全程 RMSE 与最大绝对横向误差都低于固定 MPC，且 90 m 后最大绝对误差不高于固定 MPC，然后按 50–90 m RMSE 排名。实测值与是否合格记录在 `solver_validation/lateral_validation.csv`。没有合格模型时，训练仍输出最终模型及对比指标供诊断。

## 奖励与曲线

当前三算法共用joint_tracking：横向与车身航向分别按0.2m/0.035rad归一化，权重均1，航迹角辅助权重0.05，并记录峰值、增长、转向、调参和安全分项。heading始终为车身误差，course始终为速度方向误差，不受MPC的track_course切换而混名。完整公式和真实分项诊断见最新审计。

legacy配置保留tracking_v2：横向按0.20m归一化、超0.25m另罚；其角度项按历史course语义处理。转向速率100°/s和Beta阈值5°为奖励软惩罚尺度，不能当作硬物理约束。

每个策略决策取有效控制步的加权损失均值，再扣除事件罚值。每次QP未收敛扣25，仿真失败或超时未完成扣100。末块可能少于配置的decision_steps，事件罚值不按块长度稀释。reward_scale用于C++逐步记录，桥接返回前除掉该尺度。

训练在质心首次到达或越过 X = 120 m 时结束。`manifest.json` 记录奖励版本和本次冻结的固定 MPC 配置。跟踪误差按控制后的状态样本统计。

## 负回报版本首轮验证（2026-11-02）

以下结果使用调整前的峰值奖励（阈值 0.30 m、权重 0.3）及训练参数，不能与本次新奖励的回报数值直接比较。

以当时的 TQC 参数和 60 km/h 工况从零训练 100 回合，训练回报前 20 回合均值为 **-42.13**，后 20 回合为 **-29.86**。每 500 个决策的无探索验证中，最佳检查点回报为 **-20.03**；同工况中性 MPC 为 **-23.49**。最佳检查点的横向 RMSE 为 0.05573 m（中性 0.06184 m），航向 RMSE 为 0.92284°（中性 1.00519°），两者都没有 QP 失败和附着保护步数。

验证回报有波动，最终模型回报为 -25.40，低于最佳检查点和中性 MPC。当前证据支持保存并继续验证最佳检查点，不能声称 100 回合内已经稳定收敛；应增加训练回合、不同随机种子及独立 CarSim 工况验证后再判断。

## 调整后同工况试跑（2026-11-03）

历史试验使用当时的奖励和训练参数，分别以种子 42、44 从零训练 TQC 100 回合。每回合约 55 个决策，验证间隔 550 个决策。两次训练的源 Simfile/Parsfile 指纹相同。以下为确定性策略在同一 60 km/h 工况上的结果。

| 控制器 | 验证回报 | 横向 RMSE (m) | 峰值横向误差 (m) | 航向 RMSE (°) | QP 失败 / 附着保护步数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 中性 MPC | -23.53 | 0.06184 | 0.35594 | 1.00519 | 0 / 0 |
| TQC 种子 42 最佳检查点（70 回合） | -20.85 | 0.05335 | 0.26787 | 0.98651 | 0 / 0 |
| TQC 种子 44 最佳检查点（40 回合） | -19.64 | 0.05205 | 0.28198 | 0.93504 | 0 / 0 |
| TQC 种子 42 最终模型 | -25.38 | 0.06259 | 0.34185 | 1.03137 | 0 / 0 |
| TQC 种子 44 最终模型 | -24.70 | 0.06292 | 0.31330 | 0.96686 | 0 / 0 |

两个最佳检查点均改善了本工况的横向 RMSE 和峰值误差，但最终模型均退化，训练未稳定收敛。0.25 m 是奖励开始额外惩罚的阈值，并非硬约束；本次最佳模型的峰值仍高于该值。部署前应从 `best/best_model.zip` 选模型，并在独立工况复测。详细指标与轨迹见 `runs/reward_tuning_validation/` 下两个训练目录的 `best_evaluation/` 和 `evaluation/`。
